# War Room 全球战场 · 协作单局

现有 Canvas 地图和国家视角保持不变；七阶段结算由服务端执行。无需安装 npm 依赖。

## 启动

需要 Node.js 20 或以上：

```sh
cd web
npm start
```

打开 http://127.0.0.1:3000 。多个窗口共享同一局，点击左侧国旗切换国家视角。

默认仅监听本机。局域网协作时可用 `HOST=0.0.0.0 PORT=3000 npm start`；这是无账号的协作棋盘，知道地址的人可以选择任意国家操作。

默认把每次成功操作原子保存到 `web/data/game.json`，重启自动恢复。可通过 `WARROOM_SAVE_PATH` 指定其他存档路径。页面底部的“导出存档”下载包含完整引擎状态的 JSON。恢复导出存档时，停止服务，将该文件放在指定存档路径后重新启动；开始新局时先备份并移走原存档。

## 七阶段操作

| 阶段 | 玩家选择 | 服务端处理与效果 |
|---|---|---|
| 1 国民经济 | 检查收入、确认 | 按领土与交战面加资源；中国无石油，红／灰等级不增加资源 |
| 2 战略规划 | 竞价、逐国选顺位、填写指令、重调 | 锁定展示后的竞价，统一支付石油；只接受本国现役部队、合法目的地和唯一指令；橙色等级减少3格 |
| 3 移动操作 | 执行／取消、选择完整路线、部分压制留守、出动舰载机 | 检查每条路线的相邻关系、铁路、海峡与条约；区分陆／海军压制，空军不压制；中途压制更新等待状态 |
| 4 作战行动 | 按顺位选择热点，选择姿态、投骰、命中目标、护卫、轰炸效果及战后维修 | 十二面彩色骰；空战与陆／海战、每批最多10骰／每阶段最多30骰；颜色顺序与受损优先；兵种／港口优势；潜艇下潜；常备部队、中立卫戍、领土／压力／奖章、运兵船、生产单位夺取 |
| 5 改装部署 | 空军着陆、部署、选择轰炸超额损失、重调或待入编 | 两步内友方着陆；无法着陆记伤亡；海军只部署到对应港口海区；每个现役部队最多8单位；番号不足可保留待入编 |
| 6 压力结算 | 各国依次消除压力、缓解等级、选择维稳资源、选择叛逃单位 | 伤亡值按转换表自动加压力；全体完成当前步骤后才能进入下一步；阈值升级及累计惩罚；条约失效检查 |
| 7 生产 | 购买清单、生产地、民用物资付款、中立贸易 | 检查费用、工业容量、轰炸、港口及中国限制；全体确认后统一支付；中国步兵立即动员，其他单位下一轮部署；轮末检查崩溃和全球胜利条件 |

所有必要操作完成后，阶段“确认”按钮才可用。底部“全体确认”也遵守完成条件，不能跳过未结算的战斗、移动、着陆、部署或压力步骤。

## 预览与记录

- 财务、维修、着陆、部署、重调、贸易等操作先显示预览，执行前再次核对局面版本。
- 投骰只能实际执行，不允许通过预览反复试骰。
- 不同窗口同时操作时，过期版本被拒绝并刷新；重复请求不会再次扣资源或推进阶段。
- “结算记录”查看投骰、损失、维修、控制权和资源变化；点击已完成的阶段可回看冻结记录。
- 重调弹窗只修改草稿，关闭有实际变化时进入预览；未修改就关闭不会清空指令。
- 苏日条约生效时，混合热点按苏日顺位拆成两场；第三方单位在初设时选择分组，同一单位不会重复参战。主动打破条约须预览并支付6点压力惩罚。

## 规则数据

规则依据为仓库的《作战室规则2025》：骰子分布第3页，移动第10—13页，战斗第14—19页，部署第20页，压力第21页，生产／贸易第22页，胜利第23页，条约第24页，中立国第25页，全球剧本第26页。

`rule-data.json` 从已有前端常量提取单位费用、伤亡系数、港口、护航舰队、中立国与各剧本阈值；瑞典卫戍炮兵依据规则书第25页纠正为1个。战斗姿态与命中格以仓库中的中英文战斗面板图片核对。

全球压力阈值：中4、英6、苏6、美5、德6、意4、日7；原 UI 中混用了其他剧本的阈值，现由服务端统一提供。伤亡转换表为0—18→0、20—34→1、36—50→2、52—68→3、70—88→4、90—108→5、110以上→6；伤亡系数均为偶数。

## 验证

```sh
cd web
npm test
```

测试覆盖非法输入、版本冲突、重复请求、阶段门槛、竞价、路线、压制、费用、生产、部署、重调守恒、伤亡／压力、轰炸、护航、运兵船、卫戍、条约分组、胜利、存档和传输帧。

完整浏览器回合测试可选用 Python Playwright 与 Chromium：

```sh
python -m pip install playwright
python -m playwright install chromium
cd web
python test/browser-smoke.py
```

## 本版范围

本版的可运行入口是 `web/`，使用全球剧本及仓库现有初始部署。`server/` 仍是原站前端兼容骨架，不是本版引擎入口；`site/` 仍是镜像，未改动打包程序。

欧洲、太平洋、北非、东线的部署筛选与胜利条件、快速战斗、测试模式等可选规则尚未开放。当前没有账号、房间匹配、完整操作回滚或存档导入网页。初始地图／部队是仓库既有提取数据，仍需和实体全球剧本逐卡复核；浏览器跑通与单元测试通过不能替代完整桌游对局验证。

界面示例及审阅顺序见 [UI_REVIEW.md](../docs/UI_REVIEW.md)。
